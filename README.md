🧶 Crochet Studio & Cost Calculator
Una aplicación web responsive, ligera y autónoma diseñada para tejedores de amigurumis y proyectos en crochet. Permite administrar un repositorio de insumos, calcular costos exactos de producción y estimar precios de venta sugeridos.
🚀 Características
 * Gestión de Insumos (A-Z): Registra lanas, tambores de hilo, rellenos y herrajes ordenados de forma alfabética.
 * Cotizador en Tiempo Real: Calcula el consumo exacto en gramos/unidades y suma el valor de la mano de obra según el tiempo de tejido.
 * Historial de Proyectos (Cronológico): Guarda proyectos cotizados ordenados automáticamente desde el más reciente al más antiguo.
 * Multi-moneda (COP/USD): Cambia de divisa de forma inmediata.
 * Compatibilidad Offline total: Funciona completamente en navegadores móviles (iPad, Android) y de escritorio sin requerir conexión a internet.
 * Respaldo de Datos: Permite exportar e importar datos en formato JSON.
🛠️ Tecnologías
 * HTML5
 * CSS3 (Responsive Design)
 * JavaScript (Vanilla)
 * LocalStorage para almacenamiento local en el navegador
